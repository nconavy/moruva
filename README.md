# MORUVA

여섯 친구의 작은 세계. 캐릭터, 짧은 필름, 아트 카드와 오브젝트 컬렉션을 소개하는 웹 포트폴리오입니다.

- 웹사이트: https://nconavy.github.io/moruva/
- 별도 프로젝트 — THE LOST ATLAS: https://nconavy.github.io/lost-atlas/

빌드 과정이 없는 정적 웹사이트입니다. `index.html`과 같은 폴더를 정적 HTTP 서버로 열어 확인할 수 있습니다. GitHub Pages의 `main` 브랜치 루트에서 게시합니다.

프로젝트의 캐릭터와 디자인 에셋에 대한 사용 권한은 별도 협의가 필요합니다. 외부 자료 출처 및 라이선스는 `credits.html`과 `GSAP-NOTICE.txt`를 참고하세요.
